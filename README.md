# Instagrammable Leicester

A second-year university project developed at the **University of Leicester**. The website showcases five Instagrammable locations around Leicester, providing location information, links to Instagram posts, user reviews, and accessibility features.

---

## 📍 Features

- **5 Leicester Locations** – Explore five selected Instagrammable locations around Leicester.
- **Reviews** – View and leave reviews for featured locations.
- **Login / Signup** – Basic user registration and authentication.
- **Profile Page** – Users can access their own profile page.
- **Accessibility** – Includes accessibility features to improve usability.

---

## 💻 Technologies Used

- HTML
- CSS
- JavaScript
